# Supabaseメールテンプレート設定ガイド

KUSOGETアプリケーションで使用するSupabaseのメールテンプレートを日本語でユーザーフレンドリーに設定する方法です。

## 設定手順

### 1. Supabaseダッシュボードにアクセス

1. [Supabase Dashboard](https://app.supabase.com) にログイン
2. プロジェクトを選択
3. 左メニューから「Authentication」→「Email Templates」を選択

### 2. 確認メール（Confirm signup）の設定

**Subject（件名）:**
```
KUSOGETへようこそ！メールアドレスの確認をお願いします
```

**Body（本文）:**
```html
<h2>KUSOGETへようこそ！</h2>

<p>この度は、KUSOGETにご登録いただき、ありがとうございます。</p>

<p>アカウントを有効化するために、以下のリンクをクリックしてメールアドレスを確認してください。</p>

<p><a href="{{ .ConfirmationURL }}">メールアドレスを確認する</a></p>

<p>このリンクは24時間有効です。</p>

<p>もしこのメールに心当たりがない場合は、このメールを無視していただいて構いません。</p>

<p>---</p>
<p>KUSOGET運営チーム</p>
```

**変数:**
- `{{ .ConfirmationURL }}` - 確認リンク（自動挿入）

### 3. パスワードリセットメール（Reset password）の設定

**Subject（件名）:**
```
KUSOGET - パスワードリセットのご案内
```

**Body（本文）:**
```html

<p>新しいパスワードを設定するには、以下のリンクをクリックしてください。</p>

<p><a href="{{ .ConfirmationURL }}">パスワードをリセットする</a></p>

<p>このリンクは1時間有効です。</p>

<p>もしパスワードリセットをリクエストしていない場合は、このメールを無視していただいて構いません。アカウントのセキュリティに問題はありません。</p>

<p>---</p>
<p>KUSOGET運営チーム</p>
```

## メール送信設定

### SMTP設定（オプション）

デフォルトのSupabaseメールサービスを使用する場合、設定は不要です。

独自のSMTPサーバーを使用する場合：

1. 「Authentication」→「Settings」→「SMTP Settings」に移動
2. SMTP設定を入力
3. 「Save」をクリック

## 確認事項

- [ ] 確認メールのテンプレートが日本語で設定されている
- [ ] パスワードリセットメールのテンプレートが日本語で設定されている
- [ ] メールアドレス変更確認メールのテンプレートが日本語で設定されている
- [ ] マジックリンクメールのテンプレートが日本語で設定されている
- [ ] 各メールテンプレートに適切な有効期限が記載されている
- [ ] セキュリティに関する注意書きが含まれている

## テスト方法

1. テスト用のメールアドレスでサインアップ
2. 確認メールが日本語で届くことを確認
3. メール内のリンクが正しく動作することを確認
4. メールのデザインと内容が適切であることを確認

## 注意事項

- メールテンプレートの変更は即座に反映されます
- `{{ .ConfirmationURL }}`などの変数は削除しないでください
- HTMLタグを使用してメールの見た目を調整できます
- プレーンテキスト版も設定することを推奨します（一部のメールクライアントで必要）
